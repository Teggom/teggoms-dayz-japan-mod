# Fonts for in-game Japanese text (G1 decision 5)

Both are SIL OFL 1.1 by Kinuta Font Factory, from the google/fonts repo (ofl/), fetched 2026-09-29. Licence text sits
next to each font. OFL lets us embed text rendered from them in textures; keep OFL.txt with the fonts and credit
"Yuji Project Authors" in the materials CREDITS.md when a texture uses them.

| Folder | Font | Use |
|---|---|---|
| `yujisyuku/` | Yuji Syuku (kaisho brush, 8.4 MB, full kanji set) | The main face: signs, notice boards, carved stone, lanterns |
| `yujihentaiganaakebono/` | Yuji Hentaigana Akebono (99 KB) | Hentaigana (old kana forms) for shop signs and noren, for period flavour |

The hentaigana font is small: it likely carries the hentaigana glyphs only, not the kanji. Set the kanji in Yuji
Syuku and swap the kana for Akebono's hentaigana. Check glyph coverage before relying on it.

| `notosanssiddham/` | Noto Sans Siddham (231 KB; SIL OFL 1.1, Noto Project Authors; google/fonts, fetched 2026-09-30 with Stephen's OK) | Sanskrit seed syllables (bonji / shuji) carved on gorintō and hōkyōintō graves |

Era note: Kantei-ryū lettering dates from 1779, after the 1730 cutoff; don't imitate it.
